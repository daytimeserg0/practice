# Practice — поиск вакансий

Учебное веб-приложение на Flask для поиска вакансий на hh.ru. Сервер получает HTML-страницу выдачи, извлекает вакансии, сохраняет их в PostgreSQL и показывает результаты с фильтрами по зарплате и городу.

## Возможности

- Поиск вакансий по текстовому запросу.
- Отображение названия, работодателя, города, зарплаты и ссылки на вакансию.
- Разбор зарплаты в форматах «от», «до» и диапазона значений.
- Сохранение вакансий в базе и проверка существующей записи по ссылке перед добавлением.
- Фильтрация результатов по городу, минимальной и максимальной зарплате.

## Технологии

**Python, Flask, PostgreSQL, psycopg2, Requests, Beautiful Soup, lxml, Jinja2, Bootstrap.** В репозитории также есть Dockerfile и Docker Compose.

## Backend-часть

Проект демонстрирует обработку HTTP-запросов и GET-параметров, получение данных из внешнего источника, нормализацию зарплат и сохранение результатов в реляционной базе. Работа с PostgreSQL реализована через параметризованные SQL-запросы; для проверки и добавления записей используется пул соединений `psycopg2`. HTML-ответы формируются шаблонами Jinja2.

| Маршрут | Назначение |
| --- | --- |
| `GET /` | Форма поиска |
| `GET /search` | Поиск и отображение результатов; параметры `query`, `salary_from`, `salary_to`, `city` |

## Локальный запуск

Для запуска используйте Python 3.11 или 3.12, PostgreSQL на порту `5432` и доступную системную локаль `ru_RU`: код выбирает её при импорте `parser.py`. Если возникает `unsupported locale setting`, сначала настройте эту локаль в ОС.

```bash
git clone https://github.com/daytimeserg0/practice.git
cd practice
python -m venv .venv
```

Установите зависимости в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Создайте базу и таблицу через `psql` от пользователя PostgreSQL с правом создания базы. Миграций и готового SQL-файла в репозитории нет; минимальная схема для текущего кода:

```sql
CREATE DATABASE vacancies_db;
\connect vacancies_db

CREATE TABLE vacancies (
    id SERIAL PRIMARY KEY,
    title TEXT,
    price TEXT,
    price_from INTEGER,
    price_to INTEGER,
    company TEXT,
    city TEXT,
    link TEXT
);
```

Задайте параметры подключения и запустите приложение в том же окне PowerShell. Пользователь должен иметь доступ к созданной таблице:

```powershell
$env:DB_HOST = "localhost"
$env:DB_NAME = "vacancies_db"
$env:DB_USER = "postgres"
$env:DB_PASSWORD = "ваш_пароль_PostgreSQL"
.\.venv\Scripts\python.exe app.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000). Приложение запускается в режиме отладки для локальной разработки. `.env` автоматически не загружается.

На Linux/macOS используйте `.venv/bin/python` и задайте те же переменные через `export`. Для установки `psycopg2` из исходников могут потребоваться компилятор и библиотеки разработки PostgreSQL.

## Структура

- `app.py` — HTTP-маршруты, фильтры и формирование ответов.
- `parser.py` — загрузка HTML, извлечение вакансий и разбор зарплат.
- `main.py` — SQL-запросы и подключения к PostgreSQL.
- `config.py` — параметры базы из переменных окружения.
- `templates/` — страницы поиска и результатов.

## Особенности текущей версии

Парсер обрабатывает только первую страницу выдачи hh.ru и зависит от её HTML-разметки и доступности. Используется парсинг сайта, а не API. Поиск выполняется синхронно; применение фильтров повторно загружает выдачу. Уже сохранённые вакансии повторно не обновляются. Проверка ссылки перед вставкой не защищает от дубликатов при одновременных запросах.

Docker-конфигурация требует дополнительной настройки: Compose передаёт `DATABASE_HOST` и `DATABASE_URL`, тогда как код читает `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`. В контейнере также нужно подготовить локаль `ru_RU` и таблицу `vacancies`; готового запуска одной командой в текущем состоянии нет.
